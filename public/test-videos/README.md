# Локальные тестовые ролики

`landscape.mp4` (640×360) и `portrait.mp4` (360×640): пять секунд, H.264/yuv420p,
24 fps, без звука. Созданы локально через FFmpeg из одноцветного фона и текста
«ТЕСТОВОЕ ВИДЕО / fal.ai не вызывался», без чужих материалов или инференса.

Vite копирует файлы в `dist/client/test-videos`; Docker build context включает эту
папку. Сервер читает их только для сохранённого режима test-video и копирует в
собственное хранилище сессии через обычную обработку/проверку MP4. Изменение общего
шаблона не меняет уже подготовленное видео сессии.
