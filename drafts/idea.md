**ReelMe** — веб-платформа, позволяющая человеку стать главным героем известного видео или совершенно нового AI-сгенерированного ролика.

### Функциональность

Заказчик управляет десятью видеослотами через панель администратора. Для каждого слота предусмотрено два режима:

**1. Замена персонажа в существующем видео (Video-to-Video)**

Заказчик загружает исходное видео, например популярный или вирусный ролик. AI заменяет главного персонажа на клиента, максимально сохраняя его внешность, телосложение, движения и сюжет оригинального видео.

**2. Генерация нового видео (Image-to-Video / Text-to-Video)**

Заказчик задаёт текстовый промпт, описывающий желаемое видео. AI генерирует ролик с клиентом в главной роли на основании его фотографий и промпта.

Дополнительно заказчик может загрузить **референсные изображения** — например, первый, промежуточный и последний кадры будущего видео. Эти изображения передаются AI-провайдеру вместе с фотографиями клиента и промптом для управления композицией, сценами и визуальной последовательностью ролика.

Поддержка конкретных типов референсов зависит от возможностей выбранной модели генерации.

### Процесс взаимодействия с клиентом

1. Клиент выбирает один из доступных видеослотов, представленных карточками с превью.
2. Приложение проводит автоматическую фотосессию из 5–6 кадров, последовательно показывая подсказки с позами и сопровождая съёмку звуковым отсчётом.
3. Фотографии отправляются на сервер вместе с параметрами выбранного сценария.
4. AI либо заменяет персонажа в шаблонном видео, либо генерирует новое видео по промпту и референсам.

### Техническая концепция

**Единое веб-приложение** с панелью администратора, интерфейсом фотосъёмки, управлением сценариями и облачной AI-обработкой.

Для управления USB-камерой Canon EOS 1100D на Windows 11 используется бесплатная **digiCamControl** с локальным HTTP API.

Веб-платформа имеет список указанных AI-провайдеров, с которыми она должна работать. 

**Главная идея ReelMe:** клиент выбирает понравившийся сюжет, фотографируется и получает уникальное видео, в котором главная роль принадлежит ему.
