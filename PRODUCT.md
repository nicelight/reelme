## Platform

## Users and purpose

Посетитель корпоративной фотобудки выбирает сюжет, фотографируется и получает персонализированное AI-видео по QR/email. Оператор обслуживает мероприятие; администратор управляет сюжетами. Канонический продуктовый контекст: [.memory-bank/product.md](.memory-bank/product.md) и [PRD](.memory-bank/prd.md).

## Constraints

Svelte 5, TypeScript, Vite; CSS и нативные браузерные API для motion. Съёмка сохраняет локальный origin digiCamControl. Согласованное 16 ноября 2026 новое направление интерфейса заменяет прежнюю визуальную систему.
