# Словарь ReelMe

| Термин | Значение |
|---|---|
| Заказчик / администратор | Владелец одной установки, управляющий слотами и архивом |
| Оператор / сотрудник | Помогает посетителю, открывает экран результатов и просматривает архив; не изменяет слоты и не удаляет мероприятия |
| Ключ установки | Секрет съёмочного компьютера для передачи фото и запуска генерации; не аккаунт оператора и не административный доступ |
| Посетитель / клиент | Человек, который снимается и получает своё видео |
| Слот | Настраиваемый комплект: изображение, описание, режим, модель, материалы и промпт |
| Сюжет | Представление слота посетителю, включая описание и пример видео |
| Исходное видео V2V | Материал для замены персонажа; показывается в плеере и передаётся модели |
| Демовидео P2V | Необязательный пример для просмотра; никогда не вход генерации |
| Фото посетителя | Один кадр Recast либо четыре упорядоченных ракурса одного человека |
| Референсы слота | До трёх общих изображений для P2V, дополнительных к фото посетителя |
| Фотосессия | Связь посетителя, выбранного сюжета, снимков, генерации, номера и выдачи результата |
| Номер посетителя / видео | Порядковый номер сессии внутри мероприятия; ежедневно начинается заново |
| Мероприятие | Один календарный день по Новосибирску (`Asia/Novosibirsk`) |
| Задача генерации | Фоновая обработка сессии до готового файла и формы либо окончательной ошибки; не обязательно отдельный процесс ОС |
| Подтверждение fal | Получение `request_id`, после которого новые submit для этой обработки не делаются |
| Прогресс | Шесть пользовательских этапов; не процент работы модели и не копия enum fal |
| Подтверждение email | Отправка заполненной посетителем формы; начало трёхминутного срока публичного показа |
| Видео отправлено | Успешно отправлено письмо; не утверждение о его прочтении |

Полные правила и состояния — [PRD](prd.md); технические контракты уточняются при проектировании.
