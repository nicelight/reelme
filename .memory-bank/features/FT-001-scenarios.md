# FT-001 — Настройка и выбор сюжетов

Заказчик управляет тем, что предлагается посетителю; посетитель выбирает сюжет
по изображению, описанию и видео. Каноническое поведение — [PRD](../prd.md#слоты-и-каталог).

## Acceptance Criteria

### FT-001-AC-001
- REQ: REQ-002
- Результат: слот содержит изображение и описание; админский список показывает миниатюру
  и первые три слова описания. Режим определяет доступные модели и материалы: V2V-видео
  либо до трёх P2V-референсов и необязательное демовидео, не входящее в генерацию.
  Сессия использует снимок настроек и материалов при начале съёмки; правка слота
  не меняет уже начатую сессию.
- Проверка: сохранение/открытие слотов обоих режимов и проверка полей/миниатюр в UI;
  редактирование слота между началом сессии и отправкой в fal сохраняет прежние входы сессии.

### FT-001-AC-002
- REQ: REQ-002
- Результат: у Recast поле промпта серое и недоступно; у остальных моделей промпт обязателен.
  Выбор разрешений соответствует API модели, без фиктивных вариантов для API без такого поля.
- Проверка: матрица моделей и UI настроек против [официальных схем](../analysis/fal-api.md#модели).

### FT-001-AC-003
- REQ: REQ-003
- Результат: каталог содержит только включённые слоты, по 12 на страницу; карточки
  показывают изображение и первые три слова описания. Страница сюжета показывает полное
  описание и нужное видео на половину экрана; отсутствие P2V-демо допустимо.
  «Назад» возвращает к выбору, «Мне нравится» начинает фотосессию выбранного сюжета.
- Проверка: UI-проход с более чем 12 видимыми слотами, скрытым слотом и P2V без демо.

### FT-001-AC-004
- REQ: REQ-018
- Результат: слоты изменяет администратор; аккаунт оператора, ключ установки и анонимный
  посетитель не предоставляют такого права.
- Проверка: успешное изменение администратором и отказ для остальных контекстов
  через UI и прямой запрос API.

## Реализация и проверка

Контракты слотов, снимка и доступа указаны в spec_design_links. Поля редактора
и каталога реализуются по PRD; реальную работу обоих режимов проверяет задача функции.
