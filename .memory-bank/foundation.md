# Начальная основа

## Gate Anchors
- Foundation Required: false
- Foundation Requirement: REQ-000
- Foundation Pseudo-Feature: FT-000
- Foundation Gate Task: not_required

Оператор согласовал отсутствие отдельной Foundation-очереди. REQ-000/FT-000 остаются
зарезервированными обозначениями, отдельные продуктовые требования и задачи для них
не создаются. Начальная сборка TypeScript/Svelte, запуск Fastify/SQLite и доставка
локального entrypoint входят в первую задачу со сквозным пользовательским результатом.

Она проверяет сборку, запуск с чистой БД, сохранение и чтение данных после перезапуска,
а также загрузку соответствующего интерфейса. Испытание Canon/digiCamControl относится
к FT-002 и выполняется рано из-за неопределённости реального оборудования.
Это границы будущей задачи, а не доказательство работающего приложения.
