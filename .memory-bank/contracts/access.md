# Доступ ReelMe

Основание — [роли PRD](../prd.md#поверхности-и-роли).

## Права

| Действие | Доступ |
|---|---|
| Каталог, съёмка и передача фото | Ключ установки |
| Настройка слотов | Администратор |
| Общий экран результатов | Оператор |
| Просмотр архива прошедших дней | Оператор и администратор |
| Удаление прошедшего мероприятия | Администратор |
| Форма по QR и получение видео | Ссылка конкретной сессии, без аккаунта |

Права проверяет сервер. Ключ установки не даёт административного доступа.
Полные email не показываются посетителям, ключи fal/SMTP.BZ остаются на сервере.

## Аккаунты

Два аккаунта создаются при настройке. Оператор сохраняет вход бессрочно, до явного
выхода; администратор входит заново каждые 30 дней. Это принятые сроки сессий,
а не периодическая смена паролей. Для оператора автоматического истечения нет;
серверный отзыв сессии и очистка браузерных данных прекращают сохранённый вход.

POST /api/auth/login выполняет вход, GET /api/auth/session возвращает роль,
POST /api/auth/logout завершает сессию. Сервер хранит сессии в SQLite, браузер —
идентификатор в защищённой HttpOnly-cookie. Для оператора cookie сохраняется между
запусками браузера и продлевается при использовании; браузерные ограничения хранения
не означают продуктового срока повторного входа. Пароли хранятся как hash.
Изменяющие аккаунтные запросы разрешены с нашего облачного origin.

## Установка

Случайный ключ один раз сохраняется при настройке в выделенном браузерном профиле
на http://localhost:5513. Он передаётся заголовком Authorization через HTTPS,
не включается в URL или общую клиентскую сборку. Облачные cookies для съёмки не нужны.
API и клиентские модули получают CORS-настройки для этого локального origin.
Очистка профиля потребует повторной настройки ключа.

## Ссылки посетителя

QR и ссылка скачивания относятся к одной сессии; порядковый номер не заменяет секрет
ссылки. Общий экран и архив по ним недоступны. Удаление мероприятия закрывает выдачу.
Медиа не раздаются открытым каталогом сервера.
