# EP-001 — Персонализированные видео на мероприятии

Посетитель проходит путь от выбранного сюжета до получения своего видео, а заказчик
управляет сюжетами и результатами мероприятия на одной установке.
Основание: [PRD](../prd.md), [REQ и трассировка](../requirements.md).

| Функция | Самостоятельный результат |
|---|---|
| [FT-001 Сюжеты](../features/FT-001-scenarios.md) | Заказчик настраивает предложение, посетитель выбирает понятный сюжет |
| [FT-002 Фотосессия](../features/FT-002-photo-session.md) | Получены правильные кадры посетителя, выдан номер, установка освобождена |
| [FT-003 Генерация](../features/FT-003-video-generation.md) | По снимкам и сюжету получено доступное видео либо явный итог ошибки |
| [FT-004 Публичная выдача](../features/FT-004-public-delivery.md) | Посетитель видит этапы и получает свой ролик по email через QR |
| [FT-005 Архив мероприятий](../features/FT-005-event-archive.md) | Заказчик просматривает и удаляет результаты по дням, работает автоочистка |

Архитектура и контракты связаны с функциями; реализация запланирована в
[индексе задач](../tasks/index.json). Состояния выполнения принадлежат карточкам,
наличие плана не означает готовность продукта. Отдельная Foundation-очередь
[не требуется](../foundation.md); начальная сборка/запуск входят в первую сквозную задачу.
