# TASK-011 — архив мероприятий

Реализованы GET `/api/events`, `/api/events/:date` и защищённые thumbnail/video
маршруты; CloudClient содержит раздел архива, карточки дат, галерею и плеер.
Даты ограничиваются сервером прошедшими днями Asia/Novosibirsk; снимки и номера
берутся из сохранённых сессий. Фото посетителей и кадры результатов входят в сумму
изображений, собственные MP4 — в видео; общие материалы слотов исключены.
Удаление/автоочистка остаются TASK-012. Lifecycle оставлен in_progress для владельца.

## Критерии и наблюдения

| Критерий | Реальный результат |
|---|---|
| Прошедшие даты, порядок, суммы | UI/API показывают 14, затем 13 ноября; 15 ноября — сегодня и отсутствует. Контрольный день: 7222 Б изображений, 4055 Б видео. Несколько фото одной сессии не умножают MP4/кадр; частичная и пустая съёмка не создают вымышленных файлов. |
| Полночь Новосибирска | Реальный start в 16:59:59Z 1 января, JPEG после 17:00Z сохраняет 1 января/№1; повтор start возвращает ту же сессию, новый start — 2 января/№1. Архив содержит только 1 января с фактическим размером JPEG. |
| Номер → миниатюра → своё видео | Два разных сюжета, зелёная и красная миниатюры. API сравнивает байты обеих миниатюр и MP4, проверяет Range; Chromium для обеих ролей открывает №1/№2, проверяет URL своей сессии, duration 1/2 с и продвижение currentTime. |
| Снимок после правки слота | Текущий слот имеет другую миниатюру; архив №1 возвращает прежние зелёные байты и описание. |
| Неполные результаты | №3 с одним фото и №4 без файлов остаются в галерее; videoUrl=null, кнопки disabled, прямой video — 404. |
| Доступ | API/медиа разрешены operator/admin; anonymous/receive/download credentials — 401, installation — 403. Подмена даты сессии и сегодня — 404. JSON не раскрывает provider URLs, email или capability-токены. |
| После скрытия | Email confirmation через существующий API, +180000 мс скрывает сессию на общем экране; после полуночи обоим аккаунтам доступны запись, миниатюра и MP4 архива. |
| Нет побочных действий | Сравнены generation states и все delivery records до/после API; в Chromium delivery records не менялись, запросов `/opened` — 0, page errors — 0. После рестарта архив и download сохраняются. |
