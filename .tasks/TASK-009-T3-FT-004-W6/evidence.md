# TASK-009 — локальная отправка email

Реализован Sessions worker `pending → sending → sent/failed` на настоящем Nodemailer
10.5.0. SQLite claim выполняется до сетевого I/O; HTTP и генерация не ожидают SMTP.
Видео прикладывается через `path`. Явный отказ размера/типа или ошибка файлового потока
допускает одно резервное письмо со ссылкой. Ошибки подключения/авторизации, общий
отказ DATA и потерянное подтверждение не запускают автоматический fallback/повтор.
Сохранённый `pending` продолжается при старте; `sending` становится `failed` с
`EMAIL_UNCERTAIN`, повторяет посетитель. Логи содержат только sessionId и безопасный код.

API/разметка формы из TASK-008 уже поддерживали эти состояния и предупреждение о
возможной отправке; их не меняли. Подключён реальный обработчик в жизненный цикл
Fastify, остановка ожидает текущую попытку до закрытия БД. SMTP-конфигурация серверная,
обязательный TLS, проверка сертификата, без debug. Пустые настройки оставляют worker
выключенным для локальной разработки; частичная конфигурация отклоняется.

Использованы синтетические фото/MP4 и адреса example.test, внешняя доставка отсутствует.
SMTP test server принимает соединения только на loopback и никогда не пересылает письма.

Прямой импорт Fastify из Playwright loader оказался несовместим с текущей зависимостью
`content-disposition`; браузерный сервер вынесен в отдельный Node/tsx процесс, как
существующие проектные browser fixtures. `ui_qa` launcher отсутствует, используется
согласованный project-native Playwright fallback.

Реальный SMTP.BZ и live fal не вызывались. Доставка во внешние ящики, ограничения
вложения и подпись тарифа остаются непроверенными по явному решению оператора;
локальный SMTP не объявляется доказательством этих свойств.

Реализация сверена с [SMTP transport](https://nodemailer.com/smtp),
[вложениями](https://nodemailer.com/message/attachments) и фактической обработкой
ESTREAM/DATA в установленном Nodemailer. На момент передачи code заморожен;
карточка остаётся in_progress, финальное закрытие/commit/push выполняет оркестратор.
