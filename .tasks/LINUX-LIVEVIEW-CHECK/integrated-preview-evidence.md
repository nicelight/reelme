# Превью внутри основной тестовой страницы — PASS

`/reelme-test.html` включает Live View только после ручного запуска теста и только
если Linux `/health` объявляет `features.live_view`. В `#stage` отдельный img показывает
живое зеркальное превью во время отсчёта; отдельный слой оригинального снимка удерживается
не менее 500 мс без зеркалирования. Асинхронный preview не пишет в img оригинала.

После preview-ошибки polling/Blob очищаются; между экспозициями отправляется Hide,
серия продолжается обычным Capture. Завершение/уход освобождает preview; три оригинальных
Blob сохраняются для галереи до следующего ручного запуска или ухода. gPhoto2/mock и
Windows без Linux health продолжают прежний сценарий без preview. Node/backend не менялись.

## Доказательства

- [Browser-сценарий](integrated-preview-check.mjs), [результат](integrated-preview-report.json),
  [лог](integrated-preview.log): Chromium и реальная HD User Facing 1280×720.
  Три ручные серии по три JPEG (две обычные, третья с injected preview 503).
- Все 9 оригиналов видимы **502–517 мс**, src не заменялся, preview не перекрывал
  оригинал; **56** обновлений живого изображения во время countdown.
- Обычные серии: ровно 3 `LiveView_Capture`; после injected 503 между первым и
  вторым кадрами: ровно `LiveView_Capture`, `Capture`, `Capture`. Все три JPEG
  сохранены, декодируются 1280×720, multipart HTTP200 и SHA-256/размеры совпадают.
- После серии preview скрыт, src удалён; активны ровно три Blob URL галереи,
  автоматических повторов нет. Ручной повтор успешно запускает новую серию.
  Ошибка preview явно показана. JS-исключений нет; скриншоты реальных фото не создавались.
- [Штатный mock smoke](mock-smoke-after-integrated.log): **PASS** — 3 ручные серии,
  9 JPEG, 3 загрузки, ошибки/скачивание журнала и отсутствие автоматических повторов.
- JavaScript syntax через Node `vm.Script` и `git diff --check` — PASS.

Первый browser-прогон прервала параллельная пользовательская серия: в общем filelist
появились чужие для теста фото. [Тот результат](integrated-preview-interrupted.json)
сохранён как незавершённый; итоговый изолированный повтор выше полностью прошёл.

Backend после [исправления PTS](pts-fix-evidence.md) не менялся; 120-секундный прогон
не повторялся. Сервер PID669029 продолжает работать на `http://localhost:5513`.
Открыть или перезагрузить **http://localhost:5513/reelme-test.html** и нажать
«Запустить тест». Preview включается на время серии, а не при простом открытии страницы.
