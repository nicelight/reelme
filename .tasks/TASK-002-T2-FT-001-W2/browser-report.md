# Browser QA TASK-002

Реальный Chromium, Playwright, локальная capture-страница `http://localhost:5513/reelme.html`, облачный API и Vite assets из тестового сервера `http://localhost:3197`. Временная SQLite и медиа создаются отдельно для каждого теста. Каталог подготовлен через настоящий admin API, аккаунтные cookies не передаются посетителю.

Команда: `REELME_BROWSER_ARTIFACTS=.tasks/TASK-002-T2-FT-001-W2/browser-editor-regression npm run test:ui`.

Результат финального запуска: **PASS 2/2 (12.4 s)**; capture 4.2 s, editor regression 6.1 s.

Проверено:

- Без ключа каталог, медиа и старт возвращают 401; посетитель видит просьбу позвать сотрудника без поля ключа. Сотрудник проверяет и сохраняет ключ через `#setup`; каталог открывается после reload.
- 13 включённых сюжетов и один скрытый: страницы 12+1, первые три слова названия, декодированная миниатюра. Скрытый сюжет отсутствует и возвращает 404 прямым API-запросом.
- Полное описание, возврат на вторую страницу; V2V показывает исходник, P2V — демо. Оба видео загружаются по защищённому API в blob URL и проигрываются. Без демо выводится понятный текст без сломанного плеера.
- Высота desktop-плеера — около половины viewport. Проверены desktop 1280×720 и mobile 375×812; горизонтального переполнения нет.
- «Мне нравится» получает настоящий 201, sessionId и одну позу Recast. Receipt сохраняется при reload. Видимый экран передачи к съёмке не содержит номера сессии.
- Для P2V намеренно потерян ответ после серверного commit; reload и «Повторить старт» отправляют прежний startRequestId, возвращают прежние sessionId/номер и четыре позы. В БД добавлена ровно одна строка.
- Нет ключа в request URL, cookies посетителя и page errors. Единственная намеренная сетевая ошибка — потерянное подтверждение.
- Регрессия редактора проверяет сохранение V2V/P2V, 11 моделей, persistence после restart, роли и загрузку cloud JS/CSS с локального capture origin. Старый placeholder заменён на реальное состояние настройки.

Артефакты: `browser-catalog.png`, `browser-detail.png`, `browser-mobile.png`, `browser-handoff.png`, `browser-observations.json`; редактор — `browser-editor-regression/`. Прежнее доказательство TASK-001 не перезаписано.

Первый общий запуск выявил общую БД worker fixture между файлами: capture seed попадал в editor test. Fixture переведена на отдельную временную БД для каждого теста; повтор прошёл. Продуктовых дефектов в проверенном проходе не выявлено. Проверка камеры, фото и генерации не входит в этот проход; проверена передача реальной сессии и плана поз.
