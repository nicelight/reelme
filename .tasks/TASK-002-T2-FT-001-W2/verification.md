# TASK-002 — результат

2026-11-14. Локальная разработка, Node 22.22.1, SQLite, Chromium. Реализованы
каталог установки, защищённые материалы, настройка ключа браузерного профиля и
транзакционный старт сессии со снимком сюжета. Камера и генерация не вызываются.

| Критерий | Фактическая проверка |
|---|---|
| Каталог | API и браузер: 13 включённых + один скрытый; страницы 12+1, прямой скрытый ID — 404. Миниатюры и первые три слова, полное описание, возврат на прежнюю страницу. |
| Материалы | Authorization bearer обязателен, неизвестный/скрытый/не относящийся к публичной карточке материал — 404. Реальные байты PNG/MP4 и Range 206 проверены API; V2V-исходник и P2V-демо воспроизводятся в браузере. P2V без демо доступен. |
| Доступ | Нет/неверный ключ — 401; admin/operator cookie — 403 для каталога, медиа и старта. Настройка через #setup сохраняет проверенный ключ в localStorage; ключа в URL/cookies посетителя нет. |
| Старт | Первый POST — 201, повтор — 200 с прежними ID/датой/номером/позами; другой слот с тем же ключом — 409. Новые запросы имеют разные номера; параллельный повтор создаёт одну строку. |
| Дата | Управляемое время по границе полуночи Asia/Novosibirsk: новая дата начинает с 1, повтор старой сессии сохраняет прежнюю дату и номер. Повтор после рестарта также стабилен. |
| Снимок A/B | Смена описания, модели V2V→P2V, настроек и media IDs не меняет A; B содержит новые значения. Снимки и старые байты прочитаны после restart. Демо B сохранено вне generation. |
| Handoff | Реальный sessionId и план 1/4 поз сохранены в sessionStorage; номер не показан. Потеря HTTP-ответа после commit, reload/retry: тот же startRequestId, sessionId и номер, одна новая строка БД. |
