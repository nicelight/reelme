# Выбор истории — отдельный прототип

Один вариант по `docs/DESIGN templates/2-chose-scenario.png`, в принятой палитре DESIGN.md. Проверяем крупную центральную карточку, выбор соседнего сюжета и переход к подготовке фото.

Запуск: `npm run dev:design`, затем http://localhost:5173/src/client/capture/story-prototype/index.html .

Соседние карточки, стрелки и точки меняют сюжет; ←/→ работают с клавиатуры. Кнопка выбора открывает обратимый макет подготовки. Escape возвращает к сюжетам. H скрывает демо-панель. Видео запускается вручную, останавливается при смене сюжета и скрытии вкладки. Reduced motion убирает перемещение. Нет камеры, API, сохранения или генерации; портреты иллюстративные. Только «Герой кино» использует предоставленный ролик из docs/video templates. Остальные сюжеты показывают статичный образ.

Шрифты и иллюстративный sprite скопированы из results-prototype/assets; происхождение см. соседний results-prototype/assets/PROVENANCE.md. Основной Vite entry и production routes не меняются. Композиция сохраняет широкую галерею и масштабируется на узком экране.
