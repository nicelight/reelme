# Выбор истории — отдельный прототип

Вариант по `docs/DESIGN templates/2-chose-scenario.png`, в принятой палитре [DESIGN.md](../../../../DESIGN.md#выбор-истории). Оператор принял текущий визуальный вариант 17 ноября 2026. Исходная база — [StoryPrototype.svelte](StoryPrototype.svelte); рабочий компонент — [StoryCatalog.svelte](../story/StoryCatalog.svelte), результаты переноса фиксируются в [TASK-002](../../../../.memory-bank/tasks/TASK-002-T2-FT-001-W2.task.json).

Запуск: `npm run dev:design`, затем http://localhost:5173/src/client/capture/story-prototype/index.html .

Соседние карточки, стрелки и точки меняют сюжет; ←/→ работают с клавиатуры. Кнопка выбора открывает обратимый макет подготовки. Escape возвращает к сюжетам. H скрывает демо-панель. Видео запускается вручную, останавливается при смене сюжета и скрытии вкладки. Reduced motion убирает перемещение. Нет камеры, API, сохранения или генерации; портреты иллюстративные. Только «Герой кино» использует предоставленный ролик из docs/video templates. Остальные сюжеты показывают статичный образ.

Шрифты и иллюстративный sprite скопированы из results-prototype/assets; происхождение см. соседний results-prototype/assets/PROVENANCE.md. Основной Vite entry и production routes не меняются. Композиция сохраняет широкую галерею и масштабируется на узком экране.


Принятый переход использует CSS transitions реальных bounds пяти карточек за 600ms, без покадрового JS и масштабирования текста. Полные/узкие представления постоянно присутствуют и сменяются opacity; карточка на шве карусели сначала исчезает за 140ms, переставляется невидимой и проявляется после движения соседей. Редкое пространственное переключение оправдывает более длинную кинематографическую длительность. Rapid clicks прерывают и перенаправляют переходы.

Свет рамок скопирован локально из принятого results-prototype (угловые градиенты, тонкий бело-розовый верхний блик, широкое halo). Четыре блика идут по фоновым кривым через native offset-path, проходы 7–15s, fade-in/out по 3s; скрытая вкладка останавливает движение, reduced motion оставляет статичный свет. Геометрия кривых и сливово-персиковые пятна соответствуют референсу выбора истории. Рамки не пульсируют.

Логотип assets/reelme-mark.png извлечён из предоставленного пользователем аватара: золотой R/play на прозрачном фоне; надпись REELME набрана существующим шрифтом.

При переносе карусель объединяет все доступные видимые слоты из админки: пять — только видимая композиция, при нуле показано пустое состояние без демоподстановок. Каноническое поведение — [PRD](../../../../.memory-bank/prd.md#слоты-и-каталог). Полная переработка экрана камеры этим принятием не утверждена.
