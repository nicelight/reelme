# Шаблонные ролики слотов

Папка предназначена для заранее подготовленных исходников Video-to-Video.
Ролик привязывается к **конкретному слоту**, а не к модели. На текущем этапе
созданы папка и соглашение; автоматическое подключение файлов ещё не реализовано.
Правила настройки: [матрица](../../docs/slot-setup/matrix.md).

## Имена файлов

Использовать ID сохранённого слота (UUID из редактора/API), латиницу и нижний регистр:

```text
<slot-id>__landscape.mp4
<slot-id>__portrait.mp4
```

Пример для одного слота:

```text
123e4567-e89b-42d3-a456-426614174000__landscape.mp4
123e4567-e89b-42d3-a456-426614174000__portrait.mp4
```

`landscape` — горизонтальный исходник, `portrait` — вертикальный. Достаточно одного
варианта; второй добавляется, если нужен. Это два исходника того же слота, а не
разные модели. Описание сюжета в имя не включать: оно может измениться.
Не записывать `720`/`1080` в имя: разрешение исходника и выбираемое разрешение
генерации — разные параметры.

## Формат и подготовка

Рекомендуемый совместимый формат для проекта (это правило подготовки файлов,
а не заявление о единственном формате всех API):

- Контейнер MP4, видеокодек H.264/AVC, pixel format `yuv420p`, progressive scan.
- Горизонтальный мастер: **1920×1080 (16:9)**; вертикальный: **1080×1920 (9:16)**.
  Изображение должно физически иметь нужную ориентацию, без опоры на rotation metadata.
- Постоянная частота **25 или 30 fps**; для браузерного просмотра — MP4 fast start.
- Для одного исходника, совместимого по длительности со всеми текущими V2V-моделями:
  **5–10 секунд**, не более **200 MB**. Более длинные ролики разрешены только
  после проверки предела выбранной модели по матрице/API.
- Звук необязателен; при наличии — AAC. Наличие звука в исходнике само по себе
  не задаёт политику сохранения/генерации звука моделью.
- Для Recast каждый непрерывный кадр не длиннее 15 секунд; люди хорошо различимы.
  Число и порядок заменяемых людей должны соответствовать настройкам слота.

Плеер слота должен показывать именно привязанный исходник. Если API не принимает
`aspect_ratio`, доступная ориентация зависит от исходника; приложение не будет
молча обрезать, поворачивать или увеличивать видео ради выбранного значения.
Пустая папка означает отсутствие шаблона: подставлять случайный пример запрещено.

## Подключение при внедрении

При будущей реализации выбранный файл проверяется и копируется в существующее
хранилище материалов ReelMe с собственным immutable media ID. Слот и начатая
фотосессия ссылаются на этот ID; изменение файла в этой папке не должно менять
уже начатые сессии. Локальный путь не передаётся в fal: используется существующий
механизм доступных провайдеру URL. Импорт/привязка и проверка через ffprobe входят
в план внедрения, но ещё не добавлены в код.
