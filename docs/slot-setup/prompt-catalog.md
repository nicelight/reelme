# Готовые промпты и машинная матрица

[Машинная матрица](../../src/shared/slot-setup-matrix.json) связывает 10 моделей,
100 вариантов съёмки и **843 готовых файлов `.md`** в
[public/slot-prompts](../../public/slot-prompts). Каждый файл содержит только
окончательный текст для поля промпта: без frontmatter, заголовков, переменных,
инструкций по сборке и code fences. Два файла Recast намеренно пусты.

## Выбор файла

Ключ выбора: точный `model` endpoint, `mode`, `participants` (`1`, `2`, `group`),
`photosPerParticipant` и фактический `additionalReferenceCount`.
`group` соответствует выбору «3+»; количество кадров относится ко всей группе.
Дополнительные references не включают фото камеры, обложку, P2V-демо или образцы поз.

В строке `captureVariants` массив `promptFiles` индексируется количеством
дополнительных изображений: `promptFiles[0]` — без дополнительных фото,
`promptFiles[1]` — с одним и т.д. Путь относителен к `public/slot-prompts/`.
Код не строит имя эвристикой и не подставляет переменные в текст.

[selectSlotPrompt](../../src/shared/slot-prompt-selection.ts) выполняет этот поиск
и отклоняет неподдерживаемое сочетание вместо выбора случайного промпта:

```ts
const selected = selectSlotPrompt({
  model: 'minimax/h3-max/reference-to-video',
  mode: 'P2V',
  participants: 2,
  photosPerParticipant: 4,
  additionalReferenceCount: 1,
});
// selected.file === 'h3-reference/people-2__photos-4__refs-1.md'
// selected.url  === '/slot-prompts/h3-reference/people-2__photos-4__refs-1.md'
```

После подключения выдачи файлов редактор загружает `selected.url`, проверяет
`response.ok` и вставляет `await response.text()` в textarea без Markdown-rendering.
Пустая строка Recast — успешный результат, не причина подставлять другой шаблон.
При быстрой смене выбора старый fetch не должен перезаписать новый или ручной текст.
Правила сохранения ручной правки определены [матрицей поведения](matrix.md).

**Текущее ограничение:** lookup и файлы готовы, но editor ещё не подключён.
Vite копирует `public/slot-prompts` в `dist/client/slot-prompts`; текущий Fastify
раздаёт только `/assets/`, поэтому `/slot-prompts/` требует отдельной static-route
при внедрении. Для стабильных имён не применять годовой immutable-cache от `/assets/`.
Старый `slotSchema` пока также не поддерживает новые многоперсонажные настройки.

## Примеры окончательных текстов

| Вариант | Готовый файл |
|---|---|
| H3, 2 человека × 4 кадра, 1 дополнительное фото | [открыть](../../public/slot-prompts/h3-reference/people-2__photos-4__refs-1.md) |
| Kling 4 P2V, группа, 4 кадра, 6 дополнительных фото | [открыть](../../public/slot-prompts/kling-v4-reference/group__photos-4__refs-6.md) |
| Gemini, 2 человека × 4 кадра, 2 дополнительных фото | [открыть](../../public/slot-prompts/gemini-omni-reference/people-2__photos-4__refs-2.md) |
| Recast, 2 человека × 1 кадр | [пустой файл](../../public/slot-prompts/recast/people-2__photos-1__refs-0.md) |

Для каждого сочетания есть собственный файл; одинаковые тексты намеренно не
объединяются. Разрешение, ориентация и длительность передаются параметрами API и
текст не меняют: их выбор использует тот же файл. В JSON есть допустимые quality/ratio,
но это каталог входов и файлов, не сериализованный движок всех состояний интерфейса.
Длительности и остальные действующие параметры остаются в каталоге моделей проекта.

## Подготовка и проверка набора

[Офлайн-генератор](../../scripts/generate-slot-prompts.mjs) материализует тексты
и JSON при разработке. Он не импортируется приложением, не запускается при
открытии слота и не вызывает AI. Изменения массового набора вносятся в генератор;
после них выполняется `npm run generate:slot-prompts`. Команда перезаписывает
готовые файлы, поэтому ручные изменения самих assets нужно также перенести в источник.
Ручная правка промпта в слоте не изменяет эти файлы.

По решению оператора тесты всех 800+ вариантов **не требуются**. Команда
`node --import tsx --test tests/slot-prompt-selection.test.ts` проверяет небольшую
выборку разных API-ветвей, людей/группы, границ references и пустого Recast.
Не расширять её до полного перебора и не планировать 843 UI/API/платных прогонов.

`npm run check:slot-prompts` остаётся отдельной утилитой полного сравнения с
генератором; не запускать её по умолчанию и не делать обязательным условием задач/CI.
Локальные проверки не являются свидетельством качества платной генерации.
